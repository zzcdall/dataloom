# Demo dataset

`sample_sales.csv` is a deterministic, synthetic retail dataset generated by
`generate_sample.py`. It is used by the "load demo data" button and by the tests.

| Column | Meaning |
| --- | --- |
| 订单日期 | Order date (2024-01-01 to 2025-12-31) |
| 地区 | Region |
| 品类 | Product category |
| 渠道 | Sales channel |
| 营销活动 | Whether a campaign was running |
| 销售额 | Revenue |
| 订单数 | Order count |
| 利润 | Profit |
| 客单价 | Average order value |
| 客户年龄 | Customer age |
| 满意度 | Satisfaction score (contains missing values) |
| 客户ID | Synthetic customer identifier (high cardinality) |

The data deliberately contains missing values, extreme values, and a handful of
duplicate rows so the profiling and insight engine has something to find.
